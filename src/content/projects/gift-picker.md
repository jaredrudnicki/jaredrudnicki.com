A gift recommendation tool I built with TAMID tech consulting and Presently. It reached #3 on [Product Hunt](https://www.producthunt.com/products/giftpicker-by-presently) when it launched.

## What I worked on

- A matching algorithm that ranks gifts by weighted features to find the best fit for the person you're shopping for.
- The logic for moving through the questions and for showing the results.
- Smaller features and design changes along the way.

## Tools

TypeScript, React, Tailwind CSS
